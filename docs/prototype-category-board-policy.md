# 프로토타입 카테고리·게시판 정책

## 카테고리

프로토타입과 API는 다음 6개 팀 카테고리만 사용한다.

| 화면 | API code |
|---|---|
| 롤 | `LOL` |
| 발로란트 | `VALORANT` |
| 배그 | `PUBG` |
| 피파 | `FIFA` |
| 축구·풋살 | `SOCCER_FUTSAL` |
| 농구 | `BASKETBALL` |

축구와 풋살은 별도 카테고리로 취급하지 않는다.

## 카테고리 메인 화면

카테고리 메인 화면은 해당 카테고리의 팀 카드 목록을 표시한다. 팀 카드는 다음 항목을 고정적으로 사용한다.

- 팀 이름
- 레벨: `즐겜` 또는 `빡겜`
- 장소
- 활동 시간
- 활성 멤버 수

필터는 `최신순`, `즐겜`, `빡겜`만 제공한다.

## 게시판

카테고리별 게시판은 운영하지 않는다. 모든 카테고리가 하나의 통합 게시판을 사용한다.

현재 백엔드의 `/api/categories/{category}/posts` 제거 및 통합 게시판 API 전환은 별도 작업에서 진행한다. 이번 1차 수정에서는 정책만 확정하며 기존 게시판 API를 삭제하지 않는다.
